<h1 align="center"> Color is the Key </h1>
<h3 align="center"> Project for: <a href="https://itch.io/jam/mini-jam-111-colors">Mini Jam 111-Colors</a></h3>

<h2>About The Project</h2>

<p align="justify"> 
  This project is my entry for the 111th Mini Jam-Colors. The game jam presented the limitation of: <strong>You are your own enemy</strong>. In this game, players have to solve different puzzles using given colors. But, after certain actions, the grayscale shader is applied, forcing players to remember colors and their sequences.
</p>

<h2>Instalation</h2>

<h3>Unity Project</h3>

- Clone the repository into your local machine
- Install the required Unity version
- Open the project

<h3>Release</h3>

- Download the release version
- Unpack the zip archive
- Launch the executable

<h2>Usage</h2>

- When the game is launched, players are spawned in the interactive main menu
- They can mute the game and move to the first level
- After completing the puzzle, they can move to the next level using the spawned portal

<h3>Controls</h3>

- WSAD - Movement
- E - Interaction
- R - Reload level
- Q - Go back to the Main Menu
- LMB - Shoot
- ESC - Quit application
